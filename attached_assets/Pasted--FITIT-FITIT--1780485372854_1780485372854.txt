ТЗ НА РЕДИЗАЙН FITIT
Цель
Полностью обновить визуальный стиль проекта FITIT без изменения логики, структуры экранов, расположения блоков и пользовательских сценариев.
Необходимо сохранить существующий UX и переработать только визуальную часть интерфейса.
ПОЗИЦИОНИРОВАНИЕ БРЕНДА
FITIT — персональный цифровой нутрициолог.
Это не:
фитнес-приложение
трекер калорий
спортивная программа
медицинская клиника
Это система персонального питания, которая создает рацион и ведет пользователя к цели.
ЭМОЦИИ, КОТОРЫЕ ДОЛЖЕН ВЫЗЫВАТЬ ИНТЕРФЕЙС
При использовании пользователь должен ощущать:
Доверие
Сервис выглядит серьезным и надежным.
Научность
Интерфейс создает впечатление системы, основанной на данных.
Технологичность
Современный цифровой продукт уровня 2027 года.
Простоту
Отсутствие визуального шума.
Пользователь сразу понимает, что делать дальше.

легкими

премиальными
Без тяжелых рамок.
Без сильных теней.
Основной акцент:
пространство между элементами.
КНОПКИ
Стиль:
Apple-like.
Кнопки должны выглядеть:
уверенно
спокойно
дорого
Без градиентов.
Без свечения.
Без объемных эффектов.
Основное действие всегда визуально выделено.
ИКОНКИ
Использовать только минималистичные outline-иконки.
Стиль:
Apple Human Interface Guidelines.
Не использовать:

мультяшные иконки

ГРАФИКИ

информативно

Если используются таблицы:

ФОРМЫ

простыми
современными
премиальными

Минимум декоративных элементов.
ОПРОСЫ
Дизайн должен снижать ощущение прохождения длинной анкеты.
Визуально пользователь должен воспринимать процесс как легкий диалог.
Основная задача дизайна:
уменьшить ощущение "я заполняю форму".
